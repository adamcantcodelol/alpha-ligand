How to read this

Section 4 is a pharmacophore: a list of the chemical groups a good binder should carry, and roughly where. A positively charged wall wants a negatively charged group on the ligand; an aromatic wall wants a ring to stack against; a greasy wall wants a greasy group. Build or search for a molecule that places those groups near those points, then dock and test it.

Next step: build and dock molecules — one link, one button

This page does step 1 — it profiles the pocket and tells you what chemistry a binder needs. Building actual 3D molecules and docking them into the pocket needs RDKit and AutoDock Vina, which cannot run inside a web page.

So they run in a Google Colab notebook instead: still just a link, still nothing for you to install — it installs everything it needs on Google's computer, not on yours. Fill in one form, press one play button, and it profiles the pocket, screens millions of real published compounds, docks the best ones and shows you a readable results page.

Advanced: the step-by-step notebook runs the same pipeline one cell at a time and adds the optional peptide-binder branch. Neither notebook needs anything installed on your computer.

Scores there are empirical docking estimates, not binding affinities. A good score is a reason to test a molecule, not proof that it binds.
